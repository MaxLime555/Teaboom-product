# Карточка товара Teaboom.ru

Тестовое задание: верхняя часть карточки «Ананасовый улун».
HTML5, CSS Grid/Flexbox и JavaScript. Без фреймворков, зависимостей и сборки.

## Запуск

Откройте `index.html` в браузере. Установка Node.js и пакетов не требуется.
Для Windows: Откройте PowerShell в корне проекта `start .\index.htm`

## Структура

- `index.html` — семантическая разметка, исходная фасовка 100 г.
- `styles.css` — стили, состояния элементов, адаптация.
- `script.js` — данные фасовок, изменение цены/артикула, демонстрация кнопки.
- `assets/` — локальные фото товара и логотип.

## Реализация

- Фасовки — нативные радиокнопки внутри `fieldset`: выбор мышью, касанием и клавиатурой.
- Цена, старая цена, выгода и артикул обновляются одновременно.
- Цены хранятся в копейках; форматирование — `Intl.NumberFormat` для `ru-RU`.
- Старая цена скрывается, если скидки нет.
- Изменения цены объявляются вспомогательным технологиям через `aria-live`.
- Кнопка имеет обычное состояние, hover, active и видимый фокус.
- Корзина не подключена: нажатие показывает демонстрационный текст и не отправляет запросы.
- На широком экране и планшете — две колонки, до 650 px — одна.
- Есть fallback без JavaScript и поддержка `prefers-reduced-motion`.
- Изображения локальные; внешние шрифты, библиотеки, аналитика не загружаются.
